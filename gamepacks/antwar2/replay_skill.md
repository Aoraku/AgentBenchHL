# AntWar2 回放阅读指南

回放暴露公开操作和公开效果，不直接暴露意图。分析时先验证终局有效，再把数字翻译
成带 state ID 的事实。

## 必做流程

1. 重建 tower delta：`type == -1` 删除，否则按全局塔 ID 更新。
2. 把 `op0/op1` 解码为同轮接受的原子操作；空列表为 HOLD。
3. 将 `camps/speedLv/anthpLv` 规范化为 `base_hp/generation_level/ant_level`。
4. 记录动作前金币、基地 HP、塔、蚂蚁、冷却、坐标和合法操作类型。
5. 区分下一公开状态的即时效果与若干轮后的延迟效果。
6. 比较双方角色、首次行动、首次武器、塔建造/升级/拆除顺序、武器覆盖、突破和
   资源闲置。
7. 每个判断引用 `match_id:state_id` 或连续窗口；无引用的因果解释只能标为假设。
8. 写出“公开条件 → 原子操作 → 即时效果 → 延迟效果 → 候选响应 → 证伪条件”。

不得从行为臆测隐藏目标，不得构造战术决策空间，不得按 seed、对手身份或回放 ID
写策略。Replay 只用于诊断；晋升必须通过未修改对手的自适应实战。

每轮必须保存好的、坏的、混合的、未触发的和工程失败经验。
